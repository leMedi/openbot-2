# Working in ClickUp

- ClickUp nests work as workspace → space → folder → list → task. Find the right list before creating a task in it.
- Search for an existing task before creating one; add a comment or subtask to it instead of duplicating it.
- Use the list's statuses, custom fields, due dates and assignees rather than writing them into the description.
- Change a task's status only when its work changed state, and leave a comment saying what happened.
- Link to the tasks you created or changed in your answer.
