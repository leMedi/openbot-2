# Memory lives in the database and the prompt, and is learned only from the owner's and the bot's own words

Grok Bot keeps memory as files the agent can read with Shell. Ours is a libSQL table that bots reach only through `update_state`, and a bot sees its memory only as the ranked block in its prompt: there is no search tool, so facts below the cut are visible to the owner alone. Bots have root on their machine, so files would be theirs to read and rewrite outside any review, and a table keeps the owner's UI, ownership checks and delete cascades simple. Extraction learns facts about the owner only from the owner's own words, and facts about a bot's work only from that bot's messages; tool results and other bots' words are never a source, because a prompt injection in a web page or one bot's hallucination would otherwise become a permanent fact every bot believes. A bot can still save something it read with a deliberate, reviewed write.
